# aweshare 设计哲学1：谁出算力，谁来用，谁来守门

![aweshare](../../logo/logo.png)

这是一个常见的朋友圈：有人有闲置显卡，有人的订阅额度用不完，也有人两样都没有。最直接的共享方式是把 API key 发给对方，但谁都会犹豫：把 key 交出去，等于交出了整串钥匙；超额使用、泄露或账号被封，后果都要自己承担。

aweshare 把这件事拆成三个角色：出算力的、用算力的、守门的。这篇文章不讲安装和命令，只说清楚每个角色干什么、边界在哪、背后是怎么想的。

## 生产者：有算力的人

如果你有一张闲置显卡，或一份用不完的订阅，在 aweshare 中你就是生产者。你只需要做一件事：将想共享的模型「上架」。电脑上的小程序会主动连接中转站，并将模型登记到目录中，例如「老王/qwen 大模型」；之后朋友便可按这个名字调用。

做生产者，记住三条：

- **钥匙不出门。** 你的 API key、订阅凭证，从始至终留在你自己的电脑里。别人调用时，请求被转回你的电脑，由你电脑上的程序拿着钥匙去敲上游的门。别人从头到尾看不到钥匙——连中转站也看不到。
- **你的电脑不用对外开放。** 连接是你主动打出去的，像打电话，不是开店。不用公网 IP、不用端口映射、不用动防火墙——家里闲置的笔记本、公司内网的台式机，都能当生产者。
- **护栏由你设定。** 同时服务多少人、每天最多用多少、总共放行多少，都在上架时写清楚。电脑一关机、模型一下架，共享立刻停；想再开，随时上架。

一句话：生产者共享的是**能力**，不是**钥匙**。别人能用你的模型，碰不到你的账号。

## 消费者：要算力的人

你缺一张好显卡，或是不想为一个偶尔才用的模型再开一份订阅——在 aweshare 里，你是消费者。

这个角色用起来故意做得极简：拿到令牌（一串字符）和地址，填进你本来就在用的工具——Claude Code、Codex，或任何能自定义接口的客户端——模型栏写目录里的名字，就完事了。不装新软件，不学新东西。用共享模型，跟用普通 API 供应商没两样。

看不到什么，和能用上什么一样重要：任何人的 key、提供者的真实地址、别人的流量，你统统看不到。你能看到的只有目录——谁共享了什么、在不在线、额度还剩多少。

## hub 运营者：守门的人

中转站（hub）得有人管，管的事不复杂：

- **发邀请。** 进门凭邀请码，一人一码，用一次作废。没有码，谁都进不来。
- **看电表。** 谁用了多少、什么时候用的，账目一清二楚，公平与否有据可查。
- **踩刹车。** 有人滥用时，可以限流或挂起——这些操作都可逆、可随时撤销，也不会删除历史记录。

还有一条必须如实说明的边界：**从中转站经过的所有流量，运营者在技术上都看得到。** 这不是藏着掖着的缺陷，是摆在明面上的架构事实。办法也很直接：代码完全开源，谁都可以自己搭一个。不信别人守的门，就自己守一扇。作者自己也跑着一个社区版（`https://aweshare.wehuman.top`）；不放心的话，随时自建。

## 设计哲学

三个角色背后，是几条贯穿 aweshare 的设计原则。

**共享能力，不共享钥匙。** 这是最核心的一条。钥匙给出去就是全给，收不回来；aweshare 把它换成按次、按量、随时可收回的能力。生产者的损失上限是「别人用掉的额度」，而不是「整个账号」。

**连接始终由生产者主动发起。** 生产者的电脑只往外打电话，中转站从不回拨。这样一来，「共享」就不再要求「一台暴露在公网的服务器」——家用宽带、公司内网都能出算力，这一点多数共享方案做不到。

**准入即权限，护栏即管理。** 权限模型就一句话：进了门，目录里的能力随便用。没有授权树，也没有角色配置页。公平不靠一项项审批，靠限额：每个模型、每个人的上限都摆在明处；超了就明明白白拒绝，并告诉你原因。

**诚实的边界胜过漂亮的承诺。** 中转站看得到流量，aweshare 不装作它是加密通道——边界写清楚、代码公开、想自建随时可以。协议对不上就给你清楚的报错，不会悄悄转出一个错的结果。挂起随时能恢复；该说的都摆在明处。

**只记账，不留内容。** 每个请求记一行账：谁、用了哪个模型、多少字、多久。内容本身一行不存。算清公平，有账目就够了；内容没必要留。

## 三个角色怎么碰头

最常见的场景是一群朋友：一人出显卡跑开源模型，一人共享用不完的订阅，其他人各拿一个令牌来用。门谁守都行，也可以直接用社区版 hub。安装和日常管理都能交给 AI agent——你说需求，它干活；只有启动常驻程序这一步，得你自己在终端里敲。

整套协作里，没有人需要在群里传 key；除了守门的，也没人需要买服务器。每个人的退出成本都接近零：生产者关掉程序，消费者删掉两行配置，仅此而已。

## 试试

### 让 AI agent 帮你装

在 Claude Code、Codex 或任何编程 agent 里说一句：

```text
阅读 https://github.com/wehuman01/aweshare/blob/main/README.ai.md 并按它安装和配置 aweshare。
```

### 或者自己动手

```bash
npm install -g aweshare

# 想共享（生产者）：aweshare producer init
# 想使用（消费者）：aweshare consumer join --hub <URL> --code asi_...
# 想守门（运营者）：aweshare hub init && aweshare hub invite
```
